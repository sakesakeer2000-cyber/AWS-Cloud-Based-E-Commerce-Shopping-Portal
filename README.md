# 🛒 What Is This Project?

The **AWS Cloud-Based E-Commerce Shopping Portal** is a web application built
with **Python Flask** and integrated with multiple AWS services.

The application demonstrates how a traditional web application can be
transformed into a **cloud-based application architecture** using AWS
compute, databases, storage, IAM and monitoring services.
